# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project overview

`@apitube/news-api` — the official Node.js/TypeScript SDK for the
[APITube News API](https://docs.apitube.io/). It wraps the REST API (articles,
headlines, stories, NLP analysis, reference data, account balance) behind a typed
`Client`. ESM-first with a CJS fallback, ships type declarations. Node `>=18`, MIT licensed.

## Setup

```bash
npm install
```

## Build / test / typecheck

```bash
npm run build       # tsup → dist/ (ESM index.js, CJS index.cjs, index.d.ts)
npm test            # vitest run (one-shot)
npm run test:watch  # vitest in watch mode
npm run typecheck   # tsc --noEmit (strict)
```

Tests use `axios-mock-adapter` to stub HTTP responses — no network calls.

There is **no linter or formatter configured** in this repo (no ESLint/Prettier/Biome).
Do not invent commands for tools that are not present. Match the existing code style by hand.

## Architecture

Request flow: `Client` → `Transporter` → APITube REST API → typed response objects.

- `src/index.ts` — public surface. Exports `Client`, types (`ClientOptions`,
  `NewsEndpoint`, `SuggestType`), response classes, data objects, exceptions, value objects.
- `src/Client.ts` — public entry point. Methods:
  - `news(endpoint, params, version)` — `everything` | `top-headlines` | `story` | `article` | `raw` (**POST**; `story` requires `id`)
  - `count(params, version)` — **POST**, returns `number`
  - `suggest(type, prefix, version)` — `categories` | `topics` | `industries` | `entities` (GET)
  - `people/companies/sources/journalists(params, version)` — list, return `ReferenceList` (GET)
  - `person/company/source/journalist(id, params, version)` — single profile, return object (GET)
  - `balance()` → `BalanceResponse` (GET), `ping()` → `boolean`
- `src/Transporter.ts` — HTTP layer over `axios`. `get()`, `post()`, `getRaw()`. Sends header
  `X-API-Key`, `Accept: application/json`. Maps 401 → `AuthenticationException`,
  429 → `RateLimitException`, other non-2xx → `ApiException`.
- `src/responses/` — `ArticleList`, `Article`, `ReferenceList`, `BalanceResponse`; each has a `fromArray()` factory.
- `src/dataObjects/` — value models nested inside articles (`Source`, `Author`, `Sentiment`, `Topic`, ...).
- `src/exceptions/` — `ApiException` (base), `AuthenticationException`, `RateLimitException`.
- `src/valueObjects/` — `ApiKey`, `BaseUri` (validate primitives at construction).

`examples/` mirrors each public method with a runnable script (run with `tsx`, reads `APITUBE_API_KEY` from env).

## Code style

- TypeScript in `strict` mode. The only runtime dependency is `axios`.
- ESM modules: **relative imports must end in `.js`** (e.g. `import { Transporter } from './Transporter.js'`), even though the source is `.ts`.
- 2-space indentation. Class-first design.
- Validate primitives via value objects (`ApiKey`, `BaseUri`) rather than raw strings.
- Throw status-specific exception classes; never leak raw axios errors to callers.

## Do not

- Do not edit `dist/` — it is generated by `npm run build`.
- Do not edit `node_modules/`.
- Do not bump `version` in `package.json` by hand; releases are published separately.
- Do not drop the `.js` extension from relative imports (ESM resolution will break).
- Do not hardcode or commit API keys; use the `APITUBE_API_KEY` env var (see `examples/`).
